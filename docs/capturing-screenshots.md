# Capturing the screenshots

Real captures of the running mod are now part of the repository
(`assets/screenshot.png`, `assets/screenshot-3x.png`,
`assets/registry-600x400.png`). They were taken with automated
`PrintWindow` captures of an isolated Zen 1.23.2b profile running the
mod, cropped to the top-right corner; `screenshot-3x.png` is the same
capture upscaled 3× (LANCZOS) for readability — labeled as such in the
README alt text. No mockups, no AI-generated images (`assets/preview.html`
is a design aid — never present it as evidence). The dark-theme capture
comes from the test profile; a light-theme shot would improve the set
(see the statuses in testing-guide.md).

## If you want better shots

1. Install the mod locally (testing-guide.md → Loading the mod locally).
2. `Win+Shift+S` (Snipping Tool) → window mode → click the Zen window.
3. Hover the traffic lights while snipping so the marks are revealed
   — the mark layer is what people want to see.
4. Keep the 600×400 registry shot with the discs in the upper third.
5. Commit.

Good captures show order (red/yellow/green), hover marks, and the
inactive gray state in a second window if you can fit it.

No AI-generated images. No mockups presented as the mod.
